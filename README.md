## Локальный просмотр

Распакуйте весь архив в отдельную папку. Откройте `Site/index.html` в браузере.
Внутренние ссылки и изображения работают без подключения к интернету. Ссылка на сайт ГУАП требует интернета; почтовая ссылка требует настроенного почтового приложения.

## Публикация на GitHub Pages

1. Создайте репозиторий `polyclinic-lr12` в своём аккаунте GitHub. Для бесплатного аккаунта выбирайте публичный репозиторий.
2. Загрузите содержимое папки проекта в ветку `main`, сохранив каталоги `Site`, `Этапы` и `.github/workflows`.
3. Откройте **Settings → Pages → Build and deployment → Source → GitHub Actions**.
4. В разделе **Actions** выберите **Publish clinic website → Run workflow**. При следующих изменениях в папке `Site` публикация запускается автоматически.
5. После успешного выполнения адрес действующего сайта появится в результате запуска и в **Settings → Pages**. Не подменяйте эту ссылку адресом самого репозитория: преподавателю нужен именно открывающийся сайт.

На GitHub Pages публикуется содержимое `Site`; промежуточные этапы доступны в исходниках репозитория. Сборщик и сторонние библиотеки сайту не нужны.

Документация: [автоматическая публикация сайта](https://docs.github.com/en/get-started/start-your-journey/deploying-your-website-automatically).
